# SDH - Dr. Satyanarayana | Sarojini Devi Skin Hospital, Kakinada

Official web platform for Dr. Satyanarayana, MD (Dermatology) - Sarojini Devi Skin Hospital, Bhanugudi Junction, Kakinada, Andhra Pradesh.

## Tech Stack
- React 19 + TypeScript
- Vite 8
- Tailwind CSS
- Lucide React & Motion

## Getting Started

### Prerequisites
- Node.js (v20+ recommended)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/SathyaMeka33/SDH.git
   cd SDH
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
